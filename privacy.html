Inbox Digest Privacy Policy

Effective date: 10 October 2026

Inbox Digest is a personal, read-only Gmail digest tool. It is built and used by one individual (the "owner") for his own Gmail account only. It is not offered to the public. This policy explains exactly what Google user data the tool accesses and what happens to it.

1. Data accessed

Inbox Digest asks Google for these permissions, and no others:

  • https://www.googleapis.com/auth/gmail.readonly – read-only access to Gmail messages and settings;
  • openid and https://www.googleapis.com/auth/userinfo.email – to confirm which Google Account signed in.

Within that read-only access, the tool actually reads:

  • Message metadata for messages that match the owner's saved searches: message and thread identifiers, the date received, and the From, Subject and Date headers;
  • Message content, only for receipts and invoices the owner selects: the text of the message and, when present, the attached PDF invoice, from which it keeps only lines showing an amount, a billing period or a renewal date;
  • The signed-in email address, to check that the account is the owner's.

Inbox Digest never sends, deletes, archives, labels or modifies email, and it cannot: it holds read-only access.

2. How the data is used

The data is used for one purpose: to show the owner a digest of his own inbox (what arrived, from whom, and the amounts on his receipts and invoices) so he can keep track of his own mail and spending. It is not used for advertising, profiling, credit or lending decisions, or any purpose other than that digest.

3. Storage

  • Everything stays on the owner's own computer. There is no Inbox Digest server and no cloud database.
  • The Google sign-in credential and the digest files are stored in the owner's home directory, readable only by the owner's user account on that computer.
  • Invoice PDFs that the owner chooses to read are cached in a private folder on the same computer.
  • Data is kept only as long as the owner needs it for his own records, and is deleted by him (see section 6).

4. Sharing

  • Google user data is not sold, not rented and not shared with advertisers, data brokers or any other third party.
  • No other person reads the data. The owner is the only user and the only person who sees the digest.
  • When the owner asks an AI assistant that he uses under his own account to read or summarise part of his digest, the specific lines involved are sent to that assistant's provider to answer that one request. This happens only on the owner's instruction, for his own use.
  • Google user data is not used to create, train or improve any machine-learning or artificial-intelligence model.
  • Data may be disclosed only if required by law.

5. Google API Services User Data Policy

Inbox Digest's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Deleting data and revoking access

  • Revoke access: open Google Account → Third-party apps & services, choose Inbox Digest, and remove its access. After that the tool can no longer read any mail.
  • Delete stored data: the owner deletes the credential file, the digest files and any cached invoice PDFs from his computer. Nothing is held anywhere else, so nothing else needs deleting.
  • If anyone other than the owner has ever granted Inbox Digest access by mistake, write to the contact address below: any data from that account will be deleted and the deletion confirmed by email.

7. This website

These pages are static and hosted on GitHub Pages. They set no cookies and contain no analytics or tracking. GitHub logs the IP address of visitors for security purposes, as described in the GitHub Privacy Statement.

8. Changes

If Inbox Digest ever starts using Google user data in a new way, this policy will be updated first, with a new effective date, and access will be re-granted through Google's consent screen before the new use begins.

9. Contact

Questions or deletion requests: open an issue on this repository (no personal data in public issues). As the only user, the owner can also revoke access at any time in Google Account → Security → Third-party connections.
